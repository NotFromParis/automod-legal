Install and set up AI Automod on Discord

Add Automod, run /setup and your server is protected. Here is every step in detail.

Add Automod

Add Automod to my server

  • You need the Manage Server permission to add a bot.
  • Keep the requested permissions: without them, some features can't work (creating log channels, banning, kicking…).
  • Move the Automod role above the roles of the members it should moderate (Server Settings → Roles): Discord doesn't let a bot sanction someone with a higher role.
  • If someone other than the owner adds the bot, they become the buyer and get the same Automod rights as the owner. The owner can remove them at any time.

Automatic moderation stays off until /setup is finished.

Set up with /setup

/setup (or =setup) opens the setup assistant. Like every Automod management command, it is reserved by default to the owner, the buyer, administrators and bot admins (adjustable in /controls → Permissions). Run it again at any time to redo or adjust the setup.

First run: the language

The very first time, Automod asks for its language (English or French). It applies to the whole server: messages, panels, logs, default welcome messages. Change it later with the 🌐 Langue · Language button on the /setup home screen.

⚡ Quick mode (recommended)

A preview shows exactly what will happen, then Start setup applies everything in one click:

  • a private 🛡️ Automod category with the log channels (only staff and the bot see them);
  • a private 📌 Convocations category, staff announcements going to the moderation logs;
  • the staff roles detected automatically (roles that can ban, kick, time out or manage messages);
  • the recommended protections turned on.

Nothing is deleted: channels already set up are kept. Without the Manage Channels permission, the preview warns you and nothing is created.

🛠️ Advanced mode (6 steps)

You choose everything. A progress bar shows the step, ◀️ Previous and ▶️ Next navigate, and Cancel leaves without changing anything. Nothing is saved before the last step.

StepWhat you set
1. 📋 Log channelsOne channel per log type (empty = off). ✨ Create missing creates them in the private category.
2. 👮 Staff rolesRoles exempt from anti-spam and anti-raid, pinged for convocations and allowed to read the logs. 🔎 Detect automatically finds them.
3. 🛡️ ModulesThe protections to turn on (paid-plan ones are marked). ✨ Recommended selects the advised set.
4. 🔐 PermissionsThe default for commands: Discord permission (recommended, e.g. /ban for those who can ban) or Owner only, and the bot admins (roles or members with full access).
5. 📌 ConvocationsThe convocation category and staff announcement channel (✨ Create category if needed), and the appeal link added to the DM sent to banned members.
6. 🎫 BypassChannels and roles Automod ignores (for a member or a duration: /bypass).
✅ SummaryEverything you chose, then 💾 Save.

💎 Before confirming: choosing a plan

On a Free server, Automod shows the Free, Pro and Max plans (one card each, with the price and what it adds). Subscribe to Pro / Max saves the setup and opens the payment summary; Stay on Free just saves the setup. Only the owner and the buyer can subscribe. See pricing.

Afterwards

The final screen sums up what was done and what to check (missing permissions…), with three buttons: 🎛️ Open dashboard (/controls), 🛠️ Adjust in advanced mode and 📘 User guide. Automatic moderation is active from that moment.

Test safely

=testmode on turns on test mode: the bot detects as usual but punishes no one. =testmode off turns it off and shows a report of what would have happened. Handy to tune the sensitivity before going live.

To see what the rules and the AI think of a specific message without posting it, use /iatest (or =iatest) followed by the text: Automod shows the detection, the severity, the tone and whether it would have sanctioned.
